# Data

`metadata/AUD-001.json` is the user-provided structural source audit for official MASSIVE 1.0 Azerbaijani (`az-AZ`). The first intent experiment verifies its archive, JSONL, and license hashes. Acquired originals remain under ignored `raw/`; no source data is rewritten.

Large files, raw user data, sensitive data, and restricted datasets must not be committed. Each dataset added later should document its source, license, consent or privacy constraints, preprocessing history, and split construction.

See [PR5-INT-001](../docs/experiments/PR5-INT-001.md) for verified provenance, split counts, duplicate diagnostics, and acquisition commands. Dataset license: CC BY 4.0; preserve attribution to MASSIVE and SLURP.
