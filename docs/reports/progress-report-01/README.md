# Progress Report I

This folder contains the Overleaf-ready source for Progress Report I.

## Build

Compile `main.tex` with XeLaTeX. On Overleaf, set the compiler to **XeLaTeX** and keep `references.bib` in the same folder.

Local build:

```bash
latexmk -xelatex main.tex
```

The main text is designed to satisfy the assignment's required 1,000--1,500-word range, including a 300--400-word topic description and a 150--200-word relevance and impact subsection.
