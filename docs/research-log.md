# Research log

## 2026-11-07 — PR5-INT-001: first real preliminary intent experiment

- **Attempted/completed:** acquired official MASSIVE 1.0; verified archive, Azerbaijani JSONL, and license SHA-256 values against user-provided AUD-001. Preserved AUD-001 and the original data. Implemented reusable loading/validation, majority classification, character TF-IDF + logistic regression, fixed-label metrics, ID-keyed predictions, and descriptive error analysis.
- **Decisions:** used the existing Python 3.12.4/scikit-learn 1.5.2 environment to avoid rebuilding Conda. Retained logistic regression for continuity with the methodology supplied by Bahruz. Fixed one configuration and seed 42, limited CPU numerical threads to one, preserved case and Azerbaijani characters, and retained all official records and splits. Vocabulary/IDF/model fit on train only; dev only for evaluation. Test used solely for structural validation.
- **Observed results:** 16 focused tests passed; smoke run on 180 train / 59 dev records converged. Full run on 11,514 train / 2,033 dev records converged in 66 iterations with 80,622 features and no warnings. Majority: 131 correct, accuracy 0.06443679291687161, macro-F1 0.002017868145409735. Logistic regression: 1,628 correct, accuracy 0.8007870142646335, macro-F1 0.7461142413938736. Full TF-IDF/model fit took 24.8101 seconds; dev prediction took 0.0730 seconds. Both artifact-verification runs passed without retraining; an independent standard-library count-based calculation reproduced accuracy and macro-F1 within `1e-12`.
- **Evaluation definition:** intent-only macro-F1 over all 60 training labels with `zero_division=0`. `audio_volume_other` is absent from dev and contributes zero F1. No slot or joint metrics were produced.
- **Diagnostics/interpretation:** 162 dev examples share exact text with train across 144 text groups; 12 groups contain conflicting train/dev intents. On the 1,871 dev examples absent verbatim from train, accuracy was 0.7883484767504009. Official splits were not changed. Query/action and general-question confusions warrant review; no causal linguistic or annotation-error claim is established.
