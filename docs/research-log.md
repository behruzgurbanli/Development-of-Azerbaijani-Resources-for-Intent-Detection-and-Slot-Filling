## 2026-11-07 — PR5-INT-001: first real preliminary intent experiment

- **Attempted/completed:** acquired official MASSIVE 1.0; verified archive, Azerbaijani JSONL, and license SHA-256 values against user-provided AUD-001. Preserved AUD-001 and the original data. Implemented reusable loading/validation, majority classification, character TF-IDF + logistic regression, fixed-label metrics, ID-keyed predictions, and descriptive error analysis.
- **Decisions:** used the existing Python 3.12.4/scikit-learn 1.5.2 environment to avoid rebuilding Conda. Retained logistic regression for continuity with the methodology supplied by Bahruz. Fixed one configuration and seed 42, limited CPU numerical threads to one, preserved case and Azerbaijani characters, and retained all official records and splits. Vocabulary/IDF/model fit on train only; dev only for evaluation. Test used solely for structural validation.
- **Observed results:** 16 focused tests passed; smoke run on 180 train / 59 dev records converged. Full run on 11,514 train / 2,033 dev records converged in 66 iterations with 80,622 features and no warnings. Majority: 131 correct, accuracy 0.06443679291687161, macro-F1 0.002017868145409735. Logistic regression: 1,628 correct, accuracy 0.8007870142646335, macro-F1 0.7461142413938736. Full TF-IDF/model fit took 24.8101 seconds; dev prediction took 0.0730 seconds. Both artifact-verification runs passed without retraining; an independent standard-library count-based calculation reproduced accuracy and macro-F1 within `1e-12`.
- **Evaluation definition:** intent-only macro-F1 over all 60 training labels with `zero_division=0`. `audio_volume_other` is absent from dev and contributes zero F1. No slot or joint metrics were produced.
- **Diagnostics/interpretation:** 162 dev examples share exact text with train across 144 text groups; 12 groups contain conflicting train/dev intents. On the 1,871 dev examples absent verbatim from train, accuracy was 0.7883484767504009. Official splits were not changed. Query/action and general-question confusions warrant review; no causal linguistic or annotation-error claim is established.
- **Files/artifacts:** `src/azmassive/`, `tests/test_dataset.py`, `tests/test_evaluation.py`, `configs/PR5-INT-001.json`, `requirements-pr5.txt`, `results/PR5-INT-001/`, and [the experiment record](experiments/PR5-INT-001.md). Root and component READMEs updated. Raw data/license/archive remain ignored under `data/raw/`. Existing academic reports and audit were not edited. No commit/push/PR.
- **Limitations/blockers:** no blocker remains for this CPU intent baseline. Slot extraction/alignment, CRF, XLM-R, joint evaluation, native-speaker error review, robustness analysis, and eventual test evaluation remain unimplemented or unperformed. The 6–8-page Report V still needs to be written/formatted separately. Its requirements and methodology continuity were supplied by Bahruz; earlier Reports II–IV are not present locally.

## 2026-11-21 — SLOT-CRF-001: first feature-based slot baseline

- Implemented text-only local token features, strict typed character-span scoring, ID-aligned prediction verification, and explicit IOB2 repair reporting. Reused SLOT-PREP-001 parsing, `word_punctuation` tokenization, original offsets, and BIO alignment. Fit one fixed CRFsuite L-BFGS configuration on 11,514 official train records and scored 2,033 official dev records. The test split was held out.
- Full dev precision 0.7798053528, recall 0.6432513798, micro-F1 **0.7049766291**, and utterance exact match 1,359/2,033. All-`O` F1 was zero with 647/2,033 exact matches. F1 was 0.8962264151 on 162 exact-text overlaps and 0.6931386861 on the 1,871 other records. These subgroups are descriptive. Zero invalid predicted IOB2 transitions.
- Fit took 119.7012 s, dev feature extraction and prediction 0.2634 s, and process peak RSS was 169.3125 MiB. Full training reached the 100-iteration cap. Event names, place names, and times had the most missed spans. The per-type scores and error IDs are in the experiment outputs.
- All 34 tests passed, including seven new tests. The smoke and full verifiers and an independent raw-tag count check passed. A same-host smoke repeat matched predictions, metrics, diagnostics, and model hash. Both prior intent runs still verify. See the [experiment record](experiments/SLOT-CRF-001.md) for commands, environment, earlier failed attempts, evidence, and limitations.
- Next experiment can isolate the effect of a higher iteration budget before testing morphology or context features. Full-fit and cross-platform determinism remain unmeasured. Continue using the official dev split and preserve the held-out test.

## 2026-11-22 — SLOT-CRF-002: raise the L-BFGS iteration budget

- Reused the committed CRF runner, audited MASSIVE 1.0 `az-AZ` splits (11,514 train, 2,033 dev), preprocessing, features, scoring, and all optimizer parameters except `max_iterations` (100 → 300). The test partition was held out.
- Both full fits hit their cap. Training rose from 119.7012 s to 363.8535 s (3.04×), with peak RSS of 169.3125 and 166.90625 MiB. Convergence remains unresolved.
- Dev micro-F1 rose from 0.7049766291 to **0.7224669604** (+1.7490 percentage points). The follow-up attained precision 0.8004881025, recall 0.6583040642, and 1,399/2,033 exact matches (+40). Unseen-text F1 rose from 0.6931386861 to 0.7095265926. `place_name` and `time` improved, and `event_name` declined slightly. Predictions changed on 196 utterances, with 80 becoming exact and 40 losing exact match. Both runs emitted zero invalid IOB2 transitions.
- All 34 repository tests and 7 focused CRF tests passed. Smoke matched baseline predictions and model hash; both new artifacts and both committed baseline artifacts re-verified. See the [experiment record](experiments/SLOT-CRF-002.md) and [paired comparison](../results/SLOT-CRF-002/comparison.json) for commands, hashes, timing, slot scores, and changed IDs.
- The 300-iteration model is stronger on this dev split. Gains beyond 300 are unmeasured. Do not raise the cap by default. A predeclared feature ablation at the fixed budget is the proposed next experiment.
