# AzMASSIVE data statement · draft v0.1

**2026-11-23. Unreviewed draft.** This statement describes the resource used in the benchmark. Semantic conventions and release scope await Azerbaijani-language review and supervisor confirmation. [Review procedure](annotation-review.md) · [Open decisions](thesis-gap-register.md)

**Origin and curation.** Amazon MASSIVE 1.0 localizes English-origin virtual-assistant scenarios into multiple languages. This project uses the released Azerbaijani locale `az-AZ`. Amazon and the original dataset contributors supplied the utterances, intents and slot markup. The thesis contributes integrity checks, exact annotation conversion, measured baselines, reproducible evaluation, and a review workflow. No new collection of native conversations or completed human correction layer is evidenced here. [Original dataset](https://github.com/alexa/massive) · [Source audit and CC BY 4.0 license hash](../data/metadata/AUD-001.json)

**Composition and use.** There are 16,521 records across 18 assistant scenarios, 60 intents and 55 slot types. The official train/dev/test counts are 11,514/2,033/2,974. Preserve the source IDs and split membership. A record expresses one intent and zero or more typed spans. Locale, script and task labels do not establish speaker demographics, geographic coverage or dialect representativeness. This audit verified neither individual annotator backgrounds nor the prevalence of code-switching or keyboard variation. Benchmark results apply to this localized text distribution. Claims about spontaneous speech, regional varieties, private banking dialogue or deployment require separate evidence.

**Representation and quality.** The conversion retains exact Unicode and half-open character offsets. All 13,195 train/dev spans round-tripped through IOB2. Fifty groups of repeated train/dev text had differing slot annotations. These differences can reflect context or genuine disagreement. Rare labels, unequal scenario sizes and exact-text overlap affect interpretation. Single-reviewer judgments will be kept separately from source annotations with provenance and uncertainty. [Slot audit](experiments/SLOT-PREP-001.md) · [Frozen aggregate diagnostics](../results/EVAL-FREEZE-001/held-out-breakdowns.md)

**Access and attribution.** Obtain the release from the source recorded in AUD-001. Retain the release license and attribution, cite FitzGerald et al. (2023), identify the version and describe derived transformations in any package. The repository keeps raw text, source worker identifiers, private sheets, test projections and model binaries outside new public outputs. No new participant recruitment or consent process took place in this audit. A future collection requires separate ethical and privacy review. A reviewed data statement, versioned export specification and release checks remain open. [MASSIVE paper](https://aclanthology.org/2023.acl-long.235/)
